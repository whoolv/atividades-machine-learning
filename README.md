# Atividades de Machine Learning

Atividades da disciplina de Machine Learning feitas no Google Colab.

- **atividade-machine-learning.ipynb**: lista com 20 exercícios (regressão logística, KNN, K-Means, DBSCAN, agrupamento hierárquico, árvores de decisão e MLP).
- **atividade-slide-mlp-breast-cancer.ipynb**: atividade de laboratório classificando tumores benignos e malignos com MLP no dataset Breast Cancer, comparando o treino com e sem StandardScaler.

Para rodar, é só abrir o notebook no Google Colab e executar todas as células.
